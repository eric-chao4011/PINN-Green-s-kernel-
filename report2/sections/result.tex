\begin{frame}
In another experiment, we aim to optimize the following loss function
\begin{align}
    \mathcal{L}=\frac{1}{M}\sum_{n=1}^{M}\left( \hat{G} * F_n -U_n\right)^2 + \lambda\left( \displaystyle \Delta(\hat{G} * F_n)  - F_n \right)^2.
\end{align}
Here, we fix $U_n$ and $F_n$ to the value generated by the test function
\begin{align}
    U_n&= \sin{\bigl( \pi X \bigr)}\sin{\bigl( \pi Y \bigr)},\\
    F_n&= -2\pi^2\sin{(\pi X)}\sin{(\pi Y)}.
\end{align} 
The other parameters are as same as the previous. By this experiment, we can validate whether the loss function works.
\end{frame}
